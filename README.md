# 🎬 Clone Disney+

Este projeto é um clone da interface do Disney+, desenvolvido com foco em prática de front-end, replicando a experiência visual e interativa da plataforma original.

## 📌 Sobre o projeto

O objetivo deste projeto é simular a interface do Disney+, aplicando conceitos fundamentais de desenvolvimento web como:

- Estruturação semântica com HTML5
- Estilização com CSS (metodologia BEM)
- Interatividade com JavaScript puro (Vanilla JS)
- Automação de tarefas com Gulp

A aplicação é estática e focada exclusivamente no front-end, sem integração com APIs ou backend.

---

## 🚀 Funcionalidades

- Navegação por abas (Em breve, Populares, Star+)
- FAQ interativo (abre/fecha respostas)
- Layout responsivo inspirado na plataforma original
- Organização de estilos com padrão BEM

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3 (BEM)  
- JavaScript (ES6+)  
- Gulp (automação de tarefas)

---

## ⚙️ Automação com Gulp

O projeto utiliza **Gulp** para otimizar o fluxo de desenvolvimento, incluindo:

- Compilação de arquivos CSS
- Organização dos arquivos de saída na pasta `dist`
- Preparação de assets para produção
